# Лабораторна робота №8. Створення функцій з параметрами та поверненням значення

Наскрізний проєкт з дисципліни «Основи програмування», варіант 22 —
**Особисті фінанси**.

Консольний застосунок C# (.NET 8). Це версія для здачі: код у `Program.cs`
наведено **без коментарів**.

## Що змінилося порівняно з роботою 7

Дії застосунку ті самі, але код розкладено на методи:

- `Main` містить лише налаштування, цикл меню і `switch` з однорядковими
  викликами;
- `ReadDouble` і `ReadInt` читають числа з перевіркою меж і повторюють
  запит, доки введення не стане прийнятним;
- `CalculateMonthlyBalance` повертає баланс за місяць, а не друкує його;
- `PrintBalanceTable` приймає початок, кінець і крок табулювання;
- усі числові дані вводяться тільки через `ReadDouble` або `ReadInt`.
