# Лабораторна робота №7. Табулювання функції та таблиці вкладеними циклами

Наскрізний проєкт з дисципліни «Основи програмування», варіант 22 —
**Особисті фінанси**.

Консольний застосунок C# (.NET 8). Це версія для здачі: код у `Program.cs`
наведено **без коментарів**.

## Тема проєкту

- Головна сутність: **Операція**.
- Довідник: **Категорія**.
- Поля сутності «Операція»:
  - `int` — код операції (призначає програма);
  - `DateTime` — дата операції;
  - `int` — код категорії з довідника;
  - `string` — опис операції;
  - `double` — сума, грн;
  - `string` — тип (дохід або витрата);
  - `string` — рахунок.
- Підсумкова величина: **баланс за місяць і витрати за категоріями**.

## Що реалізовано в роботі 7

1. Головне меню в циклі `while`, яке не закривається після дії. Неправильний
   пункт не завершує програму, а показує повідомлення.
2. Пункт «довідка про тему»: назва теми, головна сутність, поля з типами
   та підсумкова величина.
3. Табулювання функції: баланс за місяць залежно від середньоденної витрати.
   Дев'ять рядків, дробовий крок 50,50 грн.
4. Таблиця з двома входами: рядки — категорії, стовпці — місяці.
   Останній стовпець — підсумок рядка.
5. Рівень Б: рядок підсумків по кожному стовпцю і загальний підсумок
   в правому нижньому куті. Кількість рядків і стовпців запитується
   в користувача; нуль, від'ємне число або не число дають помилку
   й повернення в меню без побудови таблиці.

Після кожної дії — пауза й очищення екрана. Дані поки не зберігаються:
сховище на 100 записів з'явиться в наступних роботах.
